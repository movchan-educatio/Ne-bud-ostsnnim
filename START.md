# НЕ БУДЬ ОСТАННІМ — готова мобільна збірка

Це готова до запуску ігрова збірка прототипу.

## На телефоні
Опублікуй цю папку через GitHub Pages або інший HTTPS-хостинг, відкрий `index.html` у Safari/Chrome і додай гру на головний екран.

Після встановлення PWA гра запускається окремим вікном без адресного рядка та може працювати офлайн після першого завантаження.

## Що вже всередині
7 учасників (гравець + 6 ботів), велика карта, камера, фініш, зона, зброя, стрільба, перезаряджання, руйнівні ящики, лут, броня, 4 герої, здібності, турель, скіни, бали, збереження прогресу та сенсорне керування.

## Важливо
Це не підписаний файл App Store/Google Play. Для публікації в магазинах потрібна окрема збірка та підпис застосунку. Але як встановлювана мобільна PWA ця версія вже є готовою для гри.
