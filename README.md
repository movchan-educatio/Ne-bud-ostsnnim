# НЕ БУДЬ ОСТАННІМ 🎮

Готова мобільна PWA-версія гри.

## Публікація через GitHub Pages

1. Завантаж усі файли цієї папки в репозиторій.
2. У GitHub відкрий **Settings → Pages**.
3. У **Build and deployment** вибери **Deploy from a branch**.
4. Branch: `main`, Folder: `/ (root)`.
5. Збережи.
6. Відкрий адресу GitHub Pages у Safari.
7. Натисни **Поділитися → На початковий екран → Додати**.

Після цього на iPhone з'явиться іконка **НЕ БУДЬ ОСТАННІМ**, і гру можна запускати як окремий застосунок.

### Важливо
Для PWA потрібен HTTPS. GitHub Pages це забезпечує автоматично.
